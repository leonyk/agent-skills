# Runtime release origin

The base is Hugo He's official `ppt-master` v6.8.0, commit `5e8856be0da8e6bc85c4aa28acc614478f7b7137`, under `skills/ppt-master`. `runtime-lock.json` records the immutable archive URL, its SHA-256, every allowed source file, ordered patches, every changed preimage and postimage, the full rebuilt inventory, and dependency hashes.

The global installation was a read-only comparison source. The comparison covered 533 Python, Markdown, JSON, shell, web-source, YAML, and TOML files under the relevant source and documentation paths. It found 22 changed or added files. Local template libraries, indices, environment files, caches, credentials, and historical outputs were excluded from comparison and packaging.

The release retains 16 changed or added files. Four files introduce asset binding, full themes, native master defaults, and shared language binding. Nine existing Python files connect those contracts to application, conversion, validation, and preview. Three documentation files describe the same contracts. The source allowlist includes official code, docs, native conversion resources, and official ordinary templates. It excludes the optional icon and sound libraries, test files, environment samples, font files, and binary exports. The original source remains available from the pinned archive.

The MIT license and both sponsor documents are preserved byte-for-byte. The runtime includes the official SKILL identity, attribution guard, and execution gates. No guard is disabled. Oracle assets retain their original manifest, source notes, and exact bytes. Those assets are subject to the original sharing and brand-use limitations; their presence is not a new public redistribution license.

## Pruned local differences

The local `drawingml/utils.py` deletion of the `Source Han Sans SC` fallback is omitted. The full Brand theme still contains `Source Han Sans SC`. Formal slide, table, layout, and master text references theme fonts, while native chart text retains the upstream Arial and Microsoft YaHei declarations. The default alias table therefore remains official.

The local `drawingml/theme_fonts.py` generic paragraph-default feature and the corresponding `pptx_package/cli.py` policy are omitted. The preview's call to that generic policy is also omitted. The full Oracle preview, formal export, and 29 focused asset/master tests pass without these changes. Oracle's own master profile supplies its defaults.

Local `AGENTS.md` and local test modules are not runtime payload. Tests used during qualification remain audit evidence. This is a demonstrated closed patch set, not a claim of mathematically minimal source changes.

## Registration identity

The release manifest freezes both Oracle index entries generated by the pinned, patched official registrar against the exact payload. These expected values validate the selected runtime's output. They do not replace its registration command or define a second registration algorithm. Candidate entries must equal those values, including the Layout's complete page roster.

## Dependencies and limits

The only installed distributions are `python-pptx`, `PyYAML`, `Pillow`, `XlsxWriter`, `lxml`, and `typing-extensions`, with exact versions and wheel hashes in `requirements.lock`. The clean environment proves that optional AI, web, audio, Flask, PDF, and font-installation packages are unnecessary for this qualification.

The runtime was qualified on macOS arm64 with CPython 3.14.0. The manifest records Python 3.11 as the minimum, required by pinned Pillow 13; other Python versions and macOS Intel wheel selections are pinned where published but are not execution-tested here. Neither fonts nor external applications are installed. Runtime qualification does not accept the installer transaction, Codex, Cursor, or PowerPoint visual behavior.

# Oracle 模板分享包

打包日期为 2026-11-10。安装步骤见 [安装指南](安装指南.md)。

## 模板内容

- `templates/brands/oracle/` 保存 Oracle Brand 的规范、完整主题 XML、资产映射和品牌图片。
- `templates/layouts/oracle/` 保存 Oracle Layout 的规范、23 个 SVG 页面原型、母版默认值及图片。
- `install.py` 将这两个工作区复制到接收方模板库，并调用接收方的注册工具。
- `manifest.json` 保存模板文件的 SHA-256、文件大小及本次打包所用的运行时文件指纹。

两个模板的 ID 都是 `oracle`。Brand 和 Layout 属于不同的 kind，可以同时注册。

模板文件保持发送方当前版本的原始字节。分享包不包含历史 `exports/`、检查报告目录、源 PPTX、Python 依赖、发送方的模板索引或字体。

规范中的发送方绝对路径属于来源记录。接收方使用模板时不需要访问这些路径。

## 版本与依赖

本包的验证基线是发送方本地的 PPT Master 6.8.0。验证用运行时包含 Brand 主题、品牌资产映射和 Layout 母版默认值支持。版本号相同的其他安装仍须运行 `--check`。

运行时指纹只用于识别验证基线，不要求接收方的所有脚本逐字节相同。模板检查和注册结果决定本次安装能否继续。

Oracle Sans Tab 和 Source Han Sans SC 是品牌规范中的字体。两套字体均未打包。

## 来源与使用边界

这是一份从用户提供的 Oracle 模板提取并经用户调整的模板预设，不是 Oracle 官方发布的安装包。规范保留了源材料事实、模板观察、用户选择和建议之间的区别。

本包包含 Oracle 名称、标识及源模板图片。PPT Master 的 MIT 许可证不代表这些品牌资产或字体获得额外的使用及再分发许可。使用这些素材时沿用你已获得的授权。

## 校验范围

`manifest.json` 的模板哈希可以检测解压损坏或文件变化，不能证明发送者身份。ZIP 旁的 SHA-256 文件用于核对收到的整个压缩包。

`install.py --check` 在临时副本上执行接收方的模板规则检查，不向接收方模板库写入文件。`--install` 另行执行注册工具的 dry-run、正式注册、文件哈希回读，以及其他索引条目不变检查。

安装检查不等于 PowerPoint 排版验收。字体、操作系统和接收方 PPT Master 的差异可能影响最终生成的演示文稿。

## 复核文件清单

在分享包根目录运行下面的 Python 命令，可重新统计两份工作区的文件数和 SVG 原型数：

```python
from pathlib import Path

for kind in ("brands", "layouts"):
	root = Path("templates") / kind / "oracle"
	files = [path for path in root.rglob("*") if path.is_file()]
	print(kind, "files=", len(files), "svg=", len(list((root / "templates").glob("*.svg"))))
```
